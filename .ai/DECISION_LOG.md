## 格式说明

| 字段     | 说明               |
| -------- | ------------------ |
| 日期     | 决策日期           |
| 决策     | 决策内容摘要       |
| 原因     | 为什么做出此决策   |
| 替代方案 | 被否决的方案及原因 |
