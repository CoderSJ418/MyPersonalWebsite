前端性能优化是提升用户体验的关键。本文将从多个维度介绍前端性能优化的实战技巧。

## 1. 资源加载优化

### 懒加载

```typescript
// 路由懒加载
const Home = () => import('./views/Home.vue')

// 组件懒加载
const LazyComponent = defineAsyncComponent(() =>
  import('./components/LazyComponent.vue')
)
```

### 图片优化

```html
<!-- 使用 WebP 格式 -->
<picture>
  <source srcset="image.webp" type="image/webp">
  <source srcset="image.jpg" type="image/jpeg">
  <img src="image.jpg" alt="描述" loading="lazy">
</picture>
```

### 预加载和预连接

```html
<link rel="preload" href="font.woff2" as="font" type="font/woff2" crossorigin>
<link rel="preconnect" href="https://api.example.com">
```

## 2. 渲染性能优化

### 虚拟滚动

对于长列表，使用虚拟滚动只渲染可见区域的元素。

```typescript
import { useVirtualList } from '@vueuse/core'

const { list, containerProps, wrapperProps } = useVirtualList(
  Array.from({ length: 10000 }, (_, i) => ({ id: i })),
  { itemHeight: 50 }
)
```

### 防抖和节流

```typescript
import { useDebounceFn, useThrottleFn } from '@vueuse/core'

const debouncedSearch = useDebounceFn((query: string) => {
  // 搜索逻辑
}, 300)

const throttledScroll = useThrottleFn(() => {
  // 滚动逻辑
}, 100)
```

### 减少重排和重绘

```typescript
// 批量更新 DOM
const element = document.getElementById('element')
element.style.opacity = '0'
element.style.transform = 'translateX(0)'

// 使用 transform 代替 top/left
// 使用 opacity 代替 display
```

## 3. 网络优化

### HTTP/2 和 HTTP/3

确保服务器支持 HTTP/2 和 HTTP/3，以获得更好的性能。

### 缓存策略

```typescript
// Service Worker 缓存
self.addEventListener('fetch', (event) => {
  event.respondWith(
    caches.match(event.request).then((response) => {
      return response || fetch(event.request)
    })
  )
})
```

### CDN 加速

将静态资源部署到 CDN，减少网络延迟。

## 4. 代码优化

### Tree Shaking

确保构建工具启用 Tree Shaking，移除未使用的代码。

```typescript
// vite.config.ts
export default defineConfig({
  build: {
    rollupOptions: {
      output: {
        manualChunks(id) {
          if (id.includes('node_modules')) {
            return 'vendor'
          }
        }
      }
    }
  }
})
```

### 代码压缩

```typescript
export default defineConfig({
  build: {
    minify: 'terser',
    terserOptions: {
      compress: {
        drop_console: true,
        drop_debugger: true
      }
    }
  }
})
```

## 5. 监控和分析

### Lighthouse

使用 Lighthouse 进行性能审计。

### Chrome DevTools

使用 Performance 和 Network 面板分析性能瓶颈。

### Web Vitals

监控 Core Web Vitals 指标。

```typescript
import { onCLS, onFID, onFCP, onLCP, onTTFB } from 'web-vitals'

onCLS(console.log)
onFID(console.log)
onFCP(console.log)
onLCP(console.log)
onTTFB(console.log)
```

性能优化是一个持续的过程，需要不断地监控、分析和改进。
