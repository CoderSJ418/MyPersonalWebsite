## 1. 视觉层次的本质

视觉层次不是"大小对比"——它是信息重要性的视觉编码。用户在90秒内判断一个页面，靠的就是视觉层次传递的信号。

Stripe和Vercel的页面有一个共同特征：**你不需要读文字，就能知道什么最重要**。这不是天赋，是工程。

## 2. Typography Scale：字体阶梯

### 2.1 为什么不用线性递增

```css
/* ❌ 线性递增：缺乏对比 */
--font-size-1: 12px;
--font-size-2: 14px;
--font-size-3: 16px;
--font-size-4: 18px;
--font-size-5: 20px;
```

线性递增的问题：相邻级别差异太小（2px），用户无法快速区分层级。

### 2.2 Modular Scale（模块化比例）

我们使用1.25比例（Major Third）：

```
base(16px) × 1.25 = 20px
20px × 1.25 = 25px
25px × 1.25 = 31.25px → 31px
31px × 1.25 = 38.75px → 39px
```

```css
:root {
  --vs-text-xs: 0.75rem;    /* 12px */
  --vs-text-sm: 0.875rem;   /* 14px */
  --vs-text-base: 1rem;     /* 16px */
  --vs-text-lg: 1.125rem;   /* 18px */
  --vs-text-xl: 1.25rem;    /* 20px */
  --vs-text-2xl: 1.5rem;    /* 24px */
  --vs-text-3xl: 1.875rem;  /* 30px */
  --vs-text-4xl: 2.25rem;   /* 36px */
}
```

### 2.3 字重对比

```
标题: font-weight 600-700 (semibold-bold)
正文: font-weight 400 (regular)
辅助: font-weight 300 (light)
```

字重对比比字号对比更微妙但更有效——同一字号下，bold vs regular就能建立层次。

## 3. Color Hierarchy：颜色层次

### 3.1 三层颜色模型

```
Layer 1 - Primary（主色层）: 用户首先注意到的颜色
Layer 2 - Secondary（辅助层）: 支撑信息的颜色
Layer 3 - Muted（弱化层）: 背景信息的颜色
```

```css
:root {
  /* 文本层次 */
  --vs-text-primary: rgba(0, 0, 0, 0.88);    /* 标题、关键信息 */
  --vs-text-secondary: rgba(0, 0, 0, 0.65);  /* 正文、描述 */
  --vs-text-muted: rgba(0, 0, 0, 0.45);      /* 辅助信息、时间戳 */
  --vs-text-accent: #6366f1;                  /* 强调、链接、CTA */
  
  /* 表面层次 */
  --vs-surface-base: #ffffff;                 /* 页面背景 */
  --vs-surface-elevated: #ffffff;             /* 卡片背景 */
  --vs-surface-sunken: #f8fafc;               /* 凹陷区域 */
}
```

### 3.2 暗色模式的颜色翻转

```css
[data-theme="dark"] {
  --vs-text-primary: rgba(255, 255, 255, 0.92);
  --vs-text-secondary: rgba(255, 255, 255, 0.65);
  --vs-text-muted: rgba(255, 255, 255, 0.40);
  --vs-text-accent: #818cf8;
  
  --vs-surface-base: #0a0a0a;
  --vs-surface-elevated: #141414;
  --vs-surface-sunken: #050505;
}
```

暗色模式的关键不是"反转颜色"，而是**调整对比度比例**：
- 亮色模式：primary 88% → secondary 65% → muted 45%（比例约 2:1.5:1）
- 暗色模式：primary 92% → secondary 65% → muted 40%（比例约 2.3:1.6:1）

暗色背景下需要更高的primary对比度，因为人眼对暗背景上的亮文字更敏感。

### 3.3 强调色的使用克制

```css
/* ✅ 正确：强调色只用于可交互元素和关键信息 */
a, .link { color: var(--vs-text-accent); }
.cta-button { background: var(--vs-text-accent); }

/* ❌ 错误：强调色泛滥 */
h1 { color: var(--vs-text-accent); }  /* 标题不该用强调色 */
p { color: var(--vs-text-accent); }   /* 正文不该用强调色 */
```

强调色是视觉层次的"标点符号"——用太多就失去了强调效果。

## 4. Spacing Model：间距模型

### 4.1 4px基准网格

所有间距必须是4的倍数：

```css
:root {
  --vs-space-1: 0.25rem;   /* 4px */
  --vs-space-2: 0.5rem;    /* 8px */
  --vs-space-3: 0.75rem;   /* 12px */
  --vs-space-4: 1rem;      /* 16px */
  --vs-space-5: 1.5rem;    /* 24px */
  --vs-space-6: 2rem;      /* 32px */
  --vs-space-8: 3rem;      /* 48px */
  --vs-space-10: 4rem;     /* 64px */
}
```

### 4.2 间距的语义化

```css
/* ❌ 魔法数字 */
.card { padding: 24px; margin-bottom: 16px; gap: 8px; }

/* ✅ 语义化token */
.card {
  padding: var(--vs-space-5);     /* 卡片内边距 */
  margin-bottom: var(--vs-space-4); /* 卡片间距 */
  gap: var(--vs-space-2);          /* 内部元素间距 */
}
```

### 4.3 间距的层次含义

```
组件内部间距: var(--vs-space-2) ~ var(--vs-space-3)  [8-12px]
组件间距:     var(--vs-space-4) ~ var(--vs-space-5)  [16-24px]
区块间距:     var(--vs-space-6) ~ var(--vs-space-8)  [32-48px]
页面级间距:   var(--vs-space-8) ~ var(--vs-space-10) [48-64px]
```

间距越大，暗示元素之间的关系越远。这是格式塔"接近性原则"的工程化表达。

## 5. Border Radius：圆角层次

```css
:root {
  --vs-radius-sm: 0.375rem;   /* 6px - 小元素(标签、badge) */
  --vs-radius-md: 0.5rem;     /* 8px - 中等元素(输入框、按钮) */
  --vs-radius-lg: 0.75rem;    /* 12px - 大元素(卡片) */
  --vs-radius-xl: 1rem;       /* 16px - 特大元素(modal) */
  --vs-radius-full: 9999px;   /* 圆形(头像) */
}
```

圆角大小传达元素的"重量感"：
- 小圆角（6px）：精确、技术感
- 大圆角（12px+）：友好、亲和感
- 全圆角： playful、社交感

## 6. CSS @layer架构

```css
@layer base {
  /* Token定义：最底层，可被覆盖 */
  :root { --vs-text-primary: ...; }
}

@layer components {
  /* 组件样式：中间层 */
  .vs-card { ... }
  .vs-reveal { ... }
}

@layer utilities {
  /* 工具类：最高优先级 */
  .vs-text-primary { color: var(--vs-text-primary); }
}
```

@layer确保了：
1. Token定义不会被组件样式意外覆盖
2. 组件样式不会被工具类意外覆盖
3. 新旧系统（--lv-* vs --vs-*）可以共存

## 7. 总结

视觉层次工程的三个核心：
- **Typography**：Modular Scale + 字重对比，让标题"说话"
- **Color**：三层颜色模型 + 强调色克制，让重点"发光"
- **Spacing**：4px网格 + 语义化token，让关系"显形"

每个视觉决策都应该回答一个问题：**"这个像素为什么在这里？"** 如果答不出来，它就不应该存在。
